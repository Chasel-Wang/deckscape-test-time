# 口袋密室：時間測試

依照 `口袋密室企畫書.md` 與使用者提供的卡牌素材製作的靜態 HTML 遊戲。目前使用 77 張圖片，其中 13 張改用對應檔名含 `_改` 的 PNG；77 張原始 JPG、13 張替換 PNG 及一張方向介面參考圖均保留原位。無須安裝 Node.js、套件或資料庫。

## 開始遊玩

1. 使用 Chrome 或 Edge 開啟專案根目錄的 `index.html`。
2. 按「進入實驗室」，依序閱讀開場卡。
3. 完成四道帷幕設置後開始計時，可自由切換四個牌堆。
4. 已取得的物品、筆記及進度會自動保存於目前瀏覽器。

也可在 VS Code 使用 Live Server。`file://` 與 Live Server 的儲存空間各自獨立，請持續使用同一種開啟方式、同一瀏覽器與相同檔案位置。若瀏覽器拒絕 localStorage，畫面會提醒無法存檔；仍可在當前頁面遊玩並匯出文字紀錄。

## 已完成的功能

- 首頁、開始、繼續及帶確認的重新開始。
- 完整開場、四個獨立牌堆、26 道謎題、14 件物品與 A–D 四種結局。
- 單次作答鎖定、答錯繼續、已確認物品缺件的雙倍懲罰。
- 17／20／24／34 號分別取得卡片 777／電路板／密碼條／便條後才能回答；26 號取得手電筒後才公開，47 號手電筒物品面取得電池後才解鎖。
- 28 號從當下已取得物品的選單選答；46 號先選物品，再看該卡的四種方向預覽，電子卡＋180 度才正確；53 號使用四個單選選項。
- 卡牌放大／旋轉；比對畫布可用滑鼠或觸控獨立拖曳兩張卡牌。點選卡牌或 A／B 按鈕後，各自調整旋轉、縮放與透明度，並可移到最上層、一鍵並排／重疊排列或重設桌面。方向鍵微調位置，Shift＋方向鍵加速。
- 手電筒未取得電池前不顯示亮燈背面。
- 8、9 號提示卡從開場即常駐提示區，可隨時放大、旋轉；另保留單題提示、提示次數、隨身物品、筆記與作答紀錄。
- 正式開始後持續計時，離開頁面或重新整理不會暫停。
- 每個 X 加 5 分鐘，依結局抵銷 X，最低為 0；顯示原版評級。
- localStorage 存檔、錯誤存檔提示、分頁同步、文字紀錄匯出。
- 預設不顯示未解鎖卡牌，開發檢視需主動加入 `?dev=1`。

## 答案與舊存檔

26 道題目均有原文或使用者確認的答案，正常遊玩全部自動核對，不需人工選擇正確或錯誤。完整答案與物品解鎖表在 `docs/rules-notes.md`，內容包含劇透。大多數「通關」照片仍是下一張敘事卡，不會被誤當成解答背面。

座標答案 15／34／50 號接受字母數字的兩種順序，忽略大小寫、全半形、空白、標點與分隔符號，例如 `C,3`、`C3。`、`C 3`、`D,2`、`Ｂ，２` 均可接受；多餘的字母或數字仍會判錯。48 號字母順序同樣忽略空白與分隔符號，但順序必須正確。原始輸入保留於作答紀錄。

讀取舊存檔時，會用新增答案核對原本的未核對作答；保留原始答案、作答時間、物品與牌堆進度。以前因座標格式被自動判錯的正確答案也會重新核對並更新計分。已人工核對的紀錄及缺件扣分保留。新物品限制不會重置已作答題目；尚未公開的 26 號仍須有手電筒才能查看。

## 程式結構

```text
index.html                瀏覽器入口
css/style.css             響應式介面
js/cards.js               卡牌、路線、物品與結局資料
js/puzzles.js             題型、來源確認答案與已確認依賴
js/game.js                遊戲狀態、單次作答、計時、計分及存檔
js/ui.js                  介面、圖片檢視與互動
docs/card-index.md        原始素材與替換圖片盤點
docs/rules-notes.md       規則證據、數位處理及缺件清單
docs/verification.md      驗證紀錄
tests/index.html          可直接開啟的瀏覽器測試入口
tests/tests.js            純邏輯與瀏覽器操作回歸測試
00-開場/ … 05-結局/        使用者原始圖片（未修改）
```

採用一般 defer script，沒有 ES module、遠端字型、CDN、fetch 資料依賴或建置流程，直接開啟 HTML 即可離線執行。

## GitHub／Vercel 部署

將 `index.html`、`css/`、`js/` 及 `00-開場/` 至 `05-結局/` 的圖片一併提交 GitHub，保留原檔名與目錄。Vercel 匯入該儲存庫後，Root Directory 選含 `index.html` 的資料夾，Framework Preset 選 **Other**，Build Command 開啟 Override 並留空，Output Directory 使用 **`.`**。本專案沒有安裝、建置或環境變數需求；不需 SPA 重寫。設定依 [Vercel 官方靜態專案說明](https://vercel.com/docs/builds/configure-a-build#skip-build-step)。

存檔仍在玩家瀏覽器的 localStorage；本機、Vercel 預覽網址及正式網域各自獨立，不會自動搬移或跨裝置同步。目前尚未實際部署至外部服務。

## 開發與測試

在網址最後加 `?dev=1` 可開啟含劇透的素材清單。這只開放原圖檢視，不直接更改正式存檔。正式遊玩請移除這個參數。

開啟 `tests/index.html` 執行測試。UI 測試使用 `?test=1` 的獨立記憶體儲存，不更動玩家的 localStorage。若瀏覽器禁止本機 iframe 互相存取，可透過 VS Code Live Server 開啟測試入口。實際驗證使用隔離的 Chrome headless 設定目錄，結果見 `docs/verification.md`。

`.work/` 只保存素材檢視縮圖、瀏覽器測試設定與截圖，不是遊戲運作的必要檔案。純前端會在原始碼中保存答案資料，只能避免正常操作中的劇透，無法阻擋自行閱讀原始碼。

本專案可本機開啟或以靜態網站託管，目前未部署至外部服務。
